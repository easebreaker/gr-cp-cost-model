# 13 · 完整链路：公式、目的、可得的结论

这一篇是整条实验链的单页答案：**每个公式是什么、为什么是这个形式、用什么测、测出来能支撑哪一句结论。**

---

## 0. 总体目的与最终目标

**目的**：在真机跑一个配置之前，能算出它的 step 时间与显存占用；且这个能力要跨模型、跨 CP 度、跨 batch 复用。

**最终目标**（三层，逐层可独立成立）：

| 层 | 交付物 | 判据 |
|---|---|---|
| 1 | 跨模型、CP-aware 的时间与显存预测器 | 未见长度/CP/模型的留出误差 < 15% |
| 2 | 在给定显存与工期内选配置 | 排序正确率 > 90% |
| 3 | 给定质量目标的最小 GPU·h | 给出「长度 vs 容量 vs 数据」的排序 |

第 1 层不依赖质量数据；第 2 层不依赖质量数据；只有第 3 层的 `m` 最优依赖公开幂律。**这个分层是刻意的：它让前两层的结论不会被「你的质量律不准」攻击。**

## 2. 公式总表

### 2.1 工作量（②，整数，无参数）

| 量 | 公式 | 物理含义 | 为什么是这个形式 | 用什么测 |
|---|---|---|---|---|
| 静态段 pairs | `S²` | 矩形：每个 query 看整段 | 矩形面积 | 单卡切 static 比例 |
| 因果段 pairs | `[P(P+1) − S(S+1)]/2` | 移位三角 | 位置 q 的 query 带 q+1 个 key（含静态段） | 同上 |
| 候选段 pairs | `K(P+1)` | 线性 | 每个候选看前缀，只看自己 | 同上 |
| attention FLOPs | `4d·pairs` | QKᵀ + AV | 每 pair 2d 乘加 ×2 | 与大 matmul 峰值对照 |
| 逐元素字节 | `hops·6·pairs` | L² 上的 silu/mask/门控 | 每 element 2 字节 × 读写遍数 | `M3.3` 单独测 |
| 对齐因子 | `1/u(c)`, `u = c/(⌈c/BM⌉·BM)` | 尾 tile 的浪费 | 与 d 无关，只与 c 和 BM 有关 | `S1.3`：cp=3/5/6 vs 4/8 |

**为什么对齐因子只乘 attention 不乘 dense**：dense 投影按 token 切，不按 tile 切；尾 tile 浪费的是乘加 lane，不是逐元素流量。

### 2.2 效率（③a，唯一拟合）

```
eff(x) = eff∞ / (1 + (x*/x)^γ),     自变量 x = B·c = B·T/CP
```

| 锚 | 判据 | 不通过则 |
|---|---|---|
| `x* ≈ B·F/BW` | 与实测同量级（10× 内） | 曲线在补偿别的东西 → 停（G1） |
| `eff∞ ≤ F_real/F_nom` | 不超过实测峰值 | 物理不可能（G1b） |
| 自变量是 `B·c` | 标定 batch 与预测 batch 差 ≤ 2× | 越界（G7） |

**物理刻度**：`x*` 是"填满机器所需的 token 数"，约等于核数 × tile 高。

### 2.3 通信（③b，两参数 + 步数）

```
t(V) = rounds·S(N)·α + V/BW
BW_app(V) = BW/(1 + V*/V),   V* = S·α·BW
S(N) = ⌈log₂N⌉（递归倍增）  或  N−1（ring）
```

| 量 | 含义 | 为什么不能分段拟合 |
|---|---|---|
| `α` | 单步延迟 | `V*` 随 N 移动，断点跟着移动 |
| `BW` | 渐近带宽 | 小消息的"低带宽"是 α 摊薄，不是链路属性 |
| `rounds` | 每 step 集合通信次数 | jagged 会把它悄悄乘大，字节总量看不出来 |

**判据**：只用大消息拟合、预测小消息（留出）。in-sample 残差会被自由截距吃掉。

### 2.4 合成（④）

```
t_r    = recomp · ( flops/(F·eff) + hops·bytes_ew/(BW·util) + kv_hbm/(BW·util) )
         + comm(rounds, V, N)
t_step = t_fixed + t_emb + max_r t_r
```

三处非平凡组合，各有物理：

| 组合 | 为什么 | 写错会怎样 |
|---|---|---|
| `max_r` 而非平均 | 同步 step 由最慢的卡决定 | 重尾下低估 20%+ |
| 逐元素相加而非 `max` | 独立 kernel，与 GEMM 串行 | 融合了才该用 max |
| `t_fixed` 在 `max` 外 | 不随 rank 变 | 进 max 会低估加速比 |

### 2.5 目标（⑤）

```
H(L,m) = D·cp·t_step / (B·L·3600)          [GPU·h，卡数抵消]
```

**关键性质**：`cp·t_step` 下不去 → CP 不降 GPU·h。

## 3. 每项怎么测

| 量 | 作业 | 测法 | 成本 | 需 CP |
|---|---|---|---|---|
| `t_fixed` | M2.1 + M2.3 | 空 kernel 斜率 / 主干换 no-op | 4 min | 否 |
| `t_emb`、`dedup` | M2.4 | 只跑查表 + 统计唯一 id | 2.5 min | 否 |
| `bw_util` | M3.1 | 纯 copy | 1 min | 否 |
| `F_real` | M3.2 | 大 matmul | 1 min | 否 |
| `hops` | M3.3 | 分数矩阵写出再读回 | 2 min | 否 |
| `α`、`BW`、`V*` | M5.* | 7 档尺寸 × 2 个卡数 | 8 min | 否 |
| `eff` 三参数 | S1.1 | CP=1 扫 T（c ≡ T） | 13.5 min | 否 |
| 对齐因子 | S1.3 | cp=3/5/6 vs 4/8，同 kernel | 2.5 min | 否 |
| 不均衡 | S2.1 | 只跑一个 rank 的 query 行 | 18 min | 否 |
| `T_max`、`a` | M6.1 | 二分 OOM | 8 min | 否 |
| 端到端 | E1–E4 | 12+8 组 step | 84 min | **是** |

**合计 22 组、6.1 h，其中 77% 不需要 CP。**

## 4. 能得到什么结论

按"抗攻击性"从强到弱排列。这个顺序就是汇报时该用的顺序。

### 第一类：结构性的（只需几何与整数运算）

| 结论 | 依据 | 可否被数据推翻 |
|---|---|---|
| GR 的交叉点在 `T = 5d` | 无 FFN，dense 10d² vs attention 2dT | 否（是代数） |
| 掩码 pair 数是闭式 | 三段可见性规则 | 否（与暴力掩码逐项对拍） |
| 不均衡 `max/mean = 2 − 1/CP` | 纯因果连续分块 | 否（闭式） |
| 拐点 `c* = F/BW` | roofline | 否（量纲分析） |
| **CP 不降 GPU·h** | `cp·t_step` 乘积 | 否（单调性） |
| **对齐代价 `1/u(c)`** | tile 数 = ⌈c/BM⌉ | 否（整数） |

这一类的价值：**不需要任何机时就能写进论文**。而且第 5、6 条是本轮新增的。

### 第二类：需要一次外部检验的

| 结论 | 依据 | 风险 |
|---|---|---|
| 工作量计数器正确 | MTGR 三组 GFLOPs 反解同一 T（偏差 1.2%） | 低（公开数据） |
| 两个公开数字矛盾 | 1.10 vs 1.33 | 中（若 T 被误读则失效） |

### 第三类：需要自己实测的

| 结论 | 需要的作业 | 风险 |
|---|---|---|
| `eff` 的形状与刻度 | S1.1 | 低 |
| 对齐效应真实 | S1.3 | **中**（若 eff 已含此效应，则重复计算） |
| `hops` 的真实值 | M3.3 | 低 |
| 通信的步数模型 | M5.* | 低（留出检验） |
| 跨模型可迁移 | E3 | 中（G5 决定是否撤"标定一次"） |

### 第四类：条件结论（依赖质量律）

| 结论 | 依赖 | 表述方式 |
|---|---|---|
| `m` 的最优在哪 | 公开幂律的 `β` | "若质量律成立，则…" |
| `α > 0.15` 才值得翻倍长度 | `α` 指数 | 门槛随质量律变，定性结论（cp=8 不划算）不变 |

## 5. 三个"如果失败"的分支

写下来是为了在看数据之前就知道退路。

| 如果 | 则 | 退到哪 |
|---|---|---|
| `cp=1` 的 MAPE > 5%（G4） | 工作量计数器错 | 停止标定，回去对拍 |
| 换 kernel 后 `c*` 移动 > 3×（G5） | "标定一次"不成立 | 改为 kernel-aware 模型，仍可发表 |
| 对齐效应在 S1.3 上不显（G8） | kernel 不是 tile 受限 | 从模型删掉该项，避免重复计算 |
| 跨模型误差 > 20%（G6） | 迁移失败 | 改为按模型标定，缩小 claim |
| 通信留出误差大 | 实现中途换算法 | 加 `v_switch`（一个整数），不加断点 |

**每一条都有对应的作业 ID，且都在"不通过怎么办"里写了下一步。** 这是"实验设计"与"跑数据"的区别。

---

## 6. 一句话

**这条链路只有一个赌注：把不可解析性压到一维（`eff`）。** 其余公式全部可推导或可单独测量，所以：

- 标定成本只要 6.1 小时（77% 不需要 CP）；
- 结论可以分层陈述，最强的几条完全不依赖质量数据；
- 每一层失败都有明确的退路，而不是"再调调参数"。
